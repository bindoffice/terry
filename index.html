Workspace

终端分组，按目录开会话。

管理多终端标签与分组，在正确工作目录新建会话；旁侧文件面板让项目树始终在手边。

group / api cd services/api && cargo test
group / web pnpm dev --host
files crates/ · src/ · website/

Naming

支持修改分组名、终端名。

为分组和终端自定义名称，会话列表更清晰；改名结果会随工作区一起保存，下次打开仍在。

group api → shipping
terminal bash → release-build
persist saved with workspace

Split

上下左右分屏，多终端同屏协作。

将当前窗格向右、向左、向上或向下拆分，并排查看日志与命令、前后端会话或远程与本地终端。布局会随终端分组一并保存。

left · build cargo test -p terminal ok · 42 passed
right · logs tail -f /tmp/terry.log info · pane split restored
bottom · ssh ssh deploy@edge-01
